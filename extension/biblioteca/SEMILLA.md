# Semilla

Mecanismo. No trae un dominio.

La escritura es la carpeta abierta. Un proyecto nuevo empieza con ontología vacía, protegidos vacíos, sin perfil y sin lista de evidencias.

La primera operación es descubrir. Cada propuesta es una hipótesis con ancla: archivo, simbolo, hash, y tipo y relacion como etiquetas libres. El código comprueba el archivo y el hash. La confirmación es del usuario.

Sin ancla verificable, el dato queda *No confirmado en código*.

El modelo puede no consultar el canal de marcas. La verificación de citas es el control posterior.
